# TecomRed Frontend

Aplicación web de TecomRed (React + Vite + TypeScript).

## Scripts

- `npm run dev`: servidor de desarrollo.
- `npm run build`: build de producción.
- `npm run preview`: vista previa del build.
- `npm run lint`: lint del frontend.

## Notas

- El frontend usa proxy de Vite para `/api` hacia `http://localhost:4000`.
